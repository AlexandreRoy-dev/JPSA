## Aperçu local

Ouvrir `index.html` dans le navigateur, ou depuis ce dossier :

```bash
python -m http.server 4173
```

Puis : [http://127.0.0.1:4173/](http://127.0.0.1:4173/) et [http://127.0.0.1:4173/en/](http://127.0.0.1:4173/en/).
